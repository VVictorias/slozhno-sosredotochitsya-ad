# Сложно сосредоточиться

Адаптивная страница о внимании и концентрации. В проекте есть светлая и тёмная темы, а в режиме «Авто» используется цветовая схема системы.

Репозиторий: https://github.com/VVictorias/slozhno-sosredotochitsya-ad

Для локального просмотра запустите `python3 -m http.server 8794 --bind 127.0.0.1` из корня проекта. Затем откройте http://127.0.0.1:8794/.
